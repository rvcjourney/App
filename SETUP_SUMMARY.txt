HOW IT WORKS:
═══════════════════════════════════════════════════════════════════════════

  React Native App
        ↓
    needs token
        ↓
   Backend API
        ↓
   Generate fresh token
        ↓
    24-hour valid token
        ↓
   Use for meeting
        ↓
    ✅ Meeting works!


BEFORE vs AFTER:
═══════════════════════════════════════════════════════════════════════════

  BEFORE (Static Token):
    .env: REACT_APP_VIDEOSDK_TOKEN = "hardcoded..."
    Problem: Expires, visible, not scalable

  AFTER (Dynamic Token):
    .env: REACT_APP_AUTH_URL = "http://localhost:3000"
    Solution: Fresh token every time, secure, scalable
