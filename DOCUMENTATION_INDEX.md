## ⚡ Quick Reference Commands

### Backend Setup
```bash
# Navigate to backend
cd backend

# Install dependencies
npm install

# Create configuration (copy template)
cp .env.example .env
# Then edit .env with your credentials

# Start server (development)
npm start

# Start with auto-reload
npm run dev
```

### Testing Backend
```bash
# Health check
curl http://localhost:3000/health

# Get token
curl http://localhost:3000/get-token

# Validate token
curl -X POST http://localhost:3000/validate-token \
  -H "Content-Type: application/json" \
  -d '{"token":"your_token_here"}'
```

### App Configuration
```bash
# Set in app's .env
REACT_APP_AUTH_URL = "http://localhost:3000"

# For production
REACT_APP_AUTH_URL = "https://your-production-url.com"
```
