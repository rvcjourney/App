🎯 BEFORE vs AFTER
═══════════════════════════════════════════════════════════════════════════

BEFORE (Static Token - ❌ NOT RECOMMENDED)
  • Hardcoded token in .env
  • API key visible in app code
  • Expires after 24-48 hours
  • Same token for all users
  • ❌ App breaks after expiry
  • ❌ Not production ready

AFTER (Dynamic Token - ✅ RECOMMENDED)
  • Token generated on-demand
  • API key protected on backend
  • Fresh token every request
  • Unique token per meeting
  • ✅ Works forever
  • ✅ Production ready

🚀 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

  User clicks "Create Meeting"
           ↓
  App needs token
           ↓
  Request: GET /get-token
           ↓
  Backend generates fresh token
  (API Key + Secret Key + 24h expiration)
           ↓
  Response: { token: "eyJhbGc...", expiresIn: "24h" }
           ↓
  App uses token for meeting creation
           ↓
  ✅ Meeting created successfully!

🆘 QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

  Problem: "Cannot find module 'jsonwebtoken'"
  → Solution: npm install in backend folder

  Problem: "Missing VIDEOSDK_API_KEY"
  → Solution: Check backend/.env has your credentials

  Problem: "Port 3000 already in use"
  → Solution: Change PORT in backend/.env to 3001

  Problem: "Connection refused from app"
  → Solution: Make sure backend is running (npm start)

  Problem: "Token won't load in app"
  → Solution: Check REACT_APP_AUTH_URL in app's .env
